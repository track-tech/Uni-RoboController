# 11 测试策略

> 安全问题与对抗用例见 [14-adversarial-verification.md](14-adversarial-verification.md)；
> 本文覆盖常规功能/性能/兼容性测试与 CI。

## 1. 测试金字塔

```
                 ┌──────────────┐
                 │ 实机 HIL/台架 │  少量、真实、安全用例
                 ├──────────────┤
                 │ 数字孪生/仿真 │  MuJoCo/Mock + 故障注入
                 ├──────────────┤
                 │ 集成测试      │  App↔Agent 端到端、协议/会话/媒体
                 ├──────────────┤
                 │ 单元测试      │  协议/映射/缓冲/地图/状态机
                 └──────────────┘
```

## 2. 单元测试

| 模块 | 用例 |
|---|---|
| 协议编解码 | 边界值、长度、分片/重组、序号回绕、未知字段 |
| 加密/会话 | 密钥派生、重放窗口、认证失败、角色 |
| 控制/映射 | 死区、反向、曲线、组合键、多手柄槽位 |
| 看门狗/状态机 | 超时、锁存、复位、模式切换 |
| 视频 | 分片/FEC、丢帧、关键帧请求、jitter buffer |
| 深度 | zstd 编解码、无效值、内参、瓦片量化 |
| 地图 | 体素/瓦片编码、revision、限流、缓存 |
| URDF/模型 | 模型包解析、关节树、关节顺序/限位、状态插值、坐标转换、模型与状态不匹配 |
| 适配器 | 命令限幅、模式、安全动作、状态回传、模型元数据 |
| rl_sar 补丁 | 仲裁、TTL、急停、状态新鲜度（与数字孪生） |

工具：GTest/Catch2（C++）、JUnit/Kotest（Kotlin）、Hypothesis/jqwik（属性测试）。

## 3. 集成测试

- mock 机器人（UDP + 测试图 + 模拟关节状态）↔ App 端到端；
- 协议一致性：App 实现 vs Python 参考实现差分；
- 会话流程：发现→配对→连接→控制→断线→重连；
- 媒体：测试图/录播流 → 解码 → 渲染帧校验；
- 适配器：mock 机器人各形态 capability → UI 生成 → 命令回显；
- 模型：URDF→bundle 转换、下载/缓存/哈希校验、MODEL_STATE 驱动关节运动、关节顺序哈希校验；
- 兼容性：同一 App 加载四足/人形/轮足/机械臂四类模型并同步状态。

## 4. 数字孪生 / HIL

- **数字孪生**：用户已有 `l4w4_sim2sim`（MuJoCo 扮 MCU）；在链路中加故障注入代理
  （丢包/延迟/重放/状态断流/命令篡改）。所有 P0 安全用例先在此通过。
- **HIL 台架**：机器人架高/限位、限流电源、硬件急停、录像（≥120 fps）；
  先跑安全类（急停/看门狗/断链），再跑功能类；低速、保守限幅。
- **实机**：只在台架通过后进行；操作员持物理急停；记录完整日志。

## 5. 网络测试

- 参数矩阵：丢包 0–50%、延迟 0–300 ms、抖动、乱序/重复、带宽 1/20/100 Mbps、MTU/分片、断连/AP 掉电；
- 工具：`tc netem`、`iptables`、Scapy、`iperf3`、自研 UDP 代理；
- 判定：I1 始终满足；视频可降级；不允许控制误触发/失联不停止。

## 6. 设备与手柄矩阵

| 类别 | 覆盖 |
|---|---|
| Android | Pixel 6/7/8、Samsung S21/S23、小米 13/14、一台平板；Android 10–16 |
| 手柄 | Xbox One/Series（蓝牙）、DualSense、DualShock 4、Switch Pro、8BitDo、GameSir；USB-C 有线 |
| 机器人 | x86、RK3588、RK3576、RK3566（至少各一台）；rl_sar 036 实机 + 数字孪生 |
| 架构 | x86_64 原生 + aarch64 交叉（QEMU 跑协议向量）；ARM 目标板（RK3588/Jetson/Pi4）验证媒体/相机 |
| 相机 | RealSense D435/D455；USB 摄像头；ROS 2 图像源 |

每个设备记录：型号/OS/手柄模式/连接方式/结果/问题 ID。

## 7. 性能与长稳

| 测试 | 方法 | 判定 |
|---|---|---|
| 延迟 | 高速摄像机拍秒表/LED；端到端与输入到执行分开测 | 见 04/00 文档指标 |
| 帧率/抖动 | App 统计 + `dumpsys gfxinfo` + 编码/解码日志 | 无异常掉帧 |
| CPU/内存 | `top`/`pidstat`/Android Studio Profiler | 无泄漏；30 min 稳定 |
| 热 | 连续 30 min 满载；记录温度/降频 | 有明确降档策略 |
| 带宽 | `iperf3` + 协议统计 | 峰值 ≤ 链路 70% |
| 浸泡 | 8 h/48 h 连续会话 | 无崩溃/无泄漏/无断流 |

## 8. CI 与门禁

- PR：单元测试 + 协议 lint + 构建（x86 + Android debug + aarch64 交叉）；
- 每日：协议 fuzz（1 h）+ 网络损伤冒烟 + mock 端到端；
- 发布前：24 h fuzz + 48 h 浸泡 + 14 文档 P0 全绿 + 手柄/设备矩阵关键项；
- 产物：测试报告、录像、日志包；失败用例自动建 Issue。
