# 协议兼容矩阵

> 记录 App ↔ Agent ↔ 适配器 ↔ rl_sar 补丁的版本组合与测试结果。
> 发布前必须更新；不兼容组合需在 Release Notes 中注明。

## 1. 协议版本规则

- `proto_major`：不兼容变更（帧头/必选字段/语义）；升大版本，旧客户端拒绝连接并提示升级。
- `proto_minor`：向后兼容（新增可选消息/字段/标志）；Agent 按客户端版本降级发送。
- capability schema：`urc-capability/v1` 独立版本；不兼容变更升 v2。
- 安全相关（急停/看门狗/仲裁）变更视为 **major**，即使线上格式未变。

## 3. 校验方式

- CI 使用 `tools/compat_matrix`：对每个（App, Agent）组合跑握手/控制/遥测/急停冒烟；
- 协议测试向量（`protocol/test-vectors/`）固定，任何实现都必须通过；
- 老版本 App 连接新 Agent：必须能连接并降级运行，或收到明确的升级错误码（0x0201）。
