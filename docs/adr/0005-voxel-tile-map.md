# ADR-0005 地图用体素瓦片 + 2D 占据栅格

- 状态：Accepted
- 日期：2026-11-18

## 背景

需要局域网增量下发、App 端 3D 渲染与导航参考；地图规模 ≥ 200 m²。

## 决定

- 机器人侧：5 cm 体素哈希 → 4 m 瓦片（u16 Morton 量化 + zstd）→ 按 App 请求下发增量。
- 同步下发 2D 占据栅格（三态，2 bit/格，zstd）作为导航/地面图层。
- 大场景 LOD（Potree 式八叉树）与 mesh（Marching Cubes + Draco）作为 v1.1 扩展。

## 理由

- 体素瓦片编码简单、增量友好、与导航栈兼容；带宽实测估算 KB/s 级。
- 2D 栅格比 3D 点云更适合“能不能走”的直觉判断。

## 后果

- 地图精度受位姿漂移影响；无 SLAM 时只承诺局部地图。
- 需处理 revision/去重/请求限流/坐标系一致性。

## 备选

- OctoMap 直接序列化（可用，但增量与客户端渲染需额外适配）。
- 全量点云/PLY（带宽不可行）。
