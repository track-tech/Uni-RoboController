# ADR-0010 自研轻量能力描述 schema

- 状态：Accepted
- 日期：2026-11-18

## 背景

需要一套描述覆盖四足/轮式/机械臂/无人机的能力模型；现有标准中：
VDA5050 factsheet 面向 AGV/AMR 车队，ros2_control 只到关节/接口层，LeRobot 偏采数，RMF 偏车队任务。
没有现成标准同时覆盖“多形态 + 遥操作 + 安全动作”。

## 决定

- 自研 `urc-capability/v1`：形态、控制模式/通道、动作（含风险等级）、限幅、超时、
  安全动作、遥测、流、地图能力、策略列表。
- 借鉴 VDA5050 的 factsheet/action 结构、ros2_control/LeRobot 的插件注册思想、RMF 的适配器分层。
- schema 独立版本化；缺失安全动作视为非法能力，拒绝加载。

## 理由

- 现有标准无法直接满足多形态遥操作；自研一层足够轻、可演进、易被社区扩展。
- 通过“能力描述 + 适配器”实现新机器人零改 App。

## 后果

- 需要维护 schema 与校验工具；生态兼容需文档与示例。
- 与 ROS 2 标准消息的映射需在适配器中完成（不重复造消息）。

## 备选

- 直接采用 VDA5050（偏车队/导航，不含关节/飞行遥操作）。
- 纯 URDF + ros2_control（无法表达模式/安全动作/遥操作语义）。
