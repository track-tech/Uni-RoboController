# ADR-0003 视频默认 H.264，HEVC 可选

- 状态：Accepted
- 日期：2026-11-18

## 背景

需在 Android 手机与 x86/RK/Jetson 机器人上硬编硬解；延迟优先；专利与兼容性需权衡。

## 决定

- 默认 H.264（Baseline/Main/High），HEVC 作为可选；AV1 仅后续评估（RK 无 AV1 编码，手机支持不均）。
- 编码器按平台选择（VAAPI/NVENC/MPP/NVMPI/V4L2），探测失败回退软件编码并告警。

## 理由

- H.264 硬解覆盖率最高、延迟低、生态成熟；RK/Intel/NVIDIA 均支持。
- HEVC 可省带宽但 Main10 兼容性与专利风险更高，作为可选而非默认。

## 后果

- 同画质下 H.264 码率高于 HEVC（局域网可接受）。
- 商用分发需评估编解码专利许可（见 12 文档）。

## 备选

- HEVC 默认（兼容性风险）。
- AV1（编码支持差、延迟/功耗不确定）。
