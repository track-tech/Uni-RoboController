# ADR-0004 传深度 + 客户端 GPU 反投影，不传点云本体

- 状态：Accepted
- 日期：2026-11-18

## 背景

需要实时点云视图与地图；640×480 点云原始约 3.5 MiB/帧，Draco 后 0.15–0.6 MB/帧，
而 Z16 深度原始 600 KiB、压缩后约 90–150 KiB/帧。

## 决定

- 实时点云由 App 使用深度图 + 内参 + 位姿在 GPU 顶点着色器反投影生成。
- 机器人侧只构建并增量下发体素地图瓦片；不发送实时点云本体。
- 深度默认 320×240@10–15 Hz + zstd，可配高档位。

## 理由

- 带宽小 1.6–6.5 倍；客户端少一次 CPU 点云解码；GPU 反投影几乎零成本。
- 地图增量带宽可忽略（KB/s 级），与点云流相比差 2–3 个数量级。

## 后果

- 点云质量受深度分辨率/内参/无效值影响；需处理 0/饱和值。
- 需要 App 端 GLES 渲染能力（点大小限制、热降频）。
- 若需要原始点云（激光雷达/外部 SLAM），通过可选点云流扩展。

## 备选

- 传 Draco 点云（带宽高、CPU 解码、无实时优势）。
- 传 mesh（结构清晰但不适合精细操作/测量）。
